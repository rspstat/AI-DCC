이미지를 컴퓨터가 인식할 수 있는 형태로 수치화(텐서화) 하는 작업은 필수적인 과정

- 이미지 데이터들은 (H, W, C) 형태의 텐서로 이루어짐
- RGB 형태의 이미지는 H * W의 2차원 텐서가 3개 쌓인 형태
- 각 픽셀은 0~255의 값을 가짐
- 모델 학습 안정성을 위해 각 픽셀의 값을 0~1사이로 스케일링 하는 과정이 필요
- Pytorch tensor 변환 시 자동으로 이루어짐

Scaling : {0, 255} -> {0, 1} (정규화)

데이터 전처리는 원시 데이터를 분석과 모델링에 적합하도록 정리하고 변환하는 작업

- 학습 효율 및 정확도 향상을 위해 진행하는 것으로 경우에 따라 모델의 성능에 막대한 영향을 끼침

CNN(Convolution Neural Network)

- 합성곱 연산을 통해 이미지의 지역 정보(Region Feature, Graphic Feature)를 학습하는 Neural Network

Computer Vision
- 컴퓨터를 통해 이미지, 비디오 등에서 정보를 추출할 수 있도록 하는 AI의 한 분야

---

MLP(Multi Layer Perceptron)

- 이미지 픽셀 값을 Flatten 시켜 Input으로 활용
- 데이터의 형상 정보 유지 못함

CNN(Convolution Neural Network)

- 이미지의 지역 정보(Region Feature)를 Input으로 사용
- 데이터의 형상 정보 유지

---

기본적인 구조

- Convolution Layer
    - Region Feature를 뽑아내기 위한 계층
- Pooling Layer
    - Feature Dimension을 줄이기 위한 계층
- Fully Connected Layer
    - 최종적인 분류를 위한 계층

Channel

- 흑백 이미지는 2차원 형상의 데이터 -> 3차원 형상으로 표현하면 1개 채널 구성
    - ex) (5, 5, 1)

Filter(=Kernel)

- 이미지의 Region 별 Feature을 찾아내기 위한 파라미터
- 이미지의 각 픽셀별로 가중치를 설정하면 엄청나게 많은 수의 파라미터 필요
    - 일반적으로 (3, 3), (4, 4)와 같은 정사각행렬로 정의

ResNet
- Convolution 연산
    - Receptive field를 가정
    - Feature map 생성
    - Feature map 을 Flatten
    - Soft-max Function으로 예측

idea:
1. 이미지는 공간에 대한 정보를 담고 있다.
2. 상관관계가 높은 영역의 계산을 한번에 해보자

Back Propagation & Convolution
- 오차 역전파법의 경우 실제 수치적으로 계산하는 방법
- Convolution은 공간적 정보를 담을거라는 Idea의 일종

Identify mapping
- Input이 x라면 output도 x인 mapping
- 이러한 매핑을 100층 1000층을 쌓으면, 그 Network는 성능이 떨어지지 않음
- 그렇다면 output 전체를 학습하는게 아니라 변화된 것만 학습한다면?

Deep Residual Learning 방향성
- 기존 방식 : x의 예측 값인 H(x)가 실제값 y와 가까워지길 원함 -> 매핑 함수 H(x)를 구하고 싶음 (기존 학습 방향)

왜 하필 F(x)를 더하는가?
- 기존방식 : $y = \sigma_1 W_2 (\sigma_2 (W_1 x))$ (잔차생략) 
- Residual Block : $y = F(x, W_i) + W_s x$ ($W_s$는 size 맞춰주는 행렬)
- $H'(x) = F'(x) + 1$ 이므로 적어도 기울기가 $1$ 유지 $\rightarrow$ Gradient Vanishing 문제 해소
- 극단적으로 최적 값이 Identity mapping 이라고 할 때, $H(x)$ 를 맞추는 것 보다 $F(x)$ 가 $0$ 임을 맞추는 것이 더 쉽다(Idea)
- 기능을 수행하는 $H(x)$ 를 맞추는 것이 숫자인 $F(x)$ 를 맞추는 것 보다 더 어렵다 (Idea)

---

잔차 학습 (Short cut Connection)

- 각 레이어에서 벌어지는 일
- 기존 Net처럼 H(x)를 구하는 것이 아닌, F(x)를 구한다.
- 수식적으로 H(x) = x + F(x) 라 맥락 비슷
- Residual Block : $y = F(x, W_i) + W_s x$ ($W_s$는 size 맞춰주는 행렬)
- Size가 달라지는 경우에는 Pooling을 거칠 때 달라지기 때문에 학습 가능한 w를 x에 곱해주어 덧셈 연산이 가능하게 함

## Study

### 1. 인공지능과 데이터 기반 문제 해결

```
Note:

목표 : AI가 어떻게 동작하는지, 데이터가 왜 핵심인지 이해.

1. 문제 정의 : 목표와 기준 설정
2. 데이터 수집 : 관련 데이터 확보 및 라벨링
3. 데이터 전처리 : 정제 및 변환
4. 모델 학습 : 모델 선택과 학습 수행
5. 평가 및 배포 : 평가 후 운영 환경 배포

----------------------------------------------------

A. 문제 정의
- 핵심 질문 리스트
    - 어떤 결과를 예측/분류/생성할 것인가?
    - 어떤 데이터를 사용할 수 있는가?
    - 정확도 몇 %여야 실용적인가?
    - 실패하였을 때 비용은?

- 나쁜 예 : "AI로 고객 만족도를 높이고 싶다."
- 좋은 예 : "최근 3개월 구매 이력 기반으로 이탈 가능 고객을 예측해 이탈률을 15% 줄인다."

----------------------------------------------------

B. 데이터 수집
- 모델의 품질은 데이터의 품질을 넘을 수 없다.
    - 내부 데이터
        - DB, 로그, CRM, ERP 시스템
        - 가장 신뢰도 높고 도메인 특화됨
    - 공공 데이터
        - AI HUB, 공공데이터포털, 통계층
        - 무료, 라벨링 완료된 경우 많음
    - 웹 크롤링
        - BeautifulSoup, Selenium 활용
        - 저작권, robots.txt 확인
    - 직접 수집 / 라벨링
        - 설문, 실험, 어노테이션 툴 활용
        - 비용이 크지만 맞춤 데이터 확보 가능

- 데이터 수집 체크포인트
    - 충분한 양? (수 백 ~ 수 천 개)
    - Bias 없는가?
    - 라벨이 있는가?
    - 저작권 문제?

----------------------------------------------------

C. 데이터 전처리
- AI 개발 과정에서 데이터 전처리 시간이 가장 많이 든다. (60 ~ 70%)

01. 결측치 처리
    - 평균 / 중앙값 대체 또는 행 제거

02. 이상치 제거
    - IQR, Z-Score 기반 탐지

03. 인코딩
    - 범주형 -> 수치형 변환 (One-Hot, Label)

04. 정규화/표준화
    - 스케일 통일 (MinMax, StandardScaler)

05. 피쳐 선택
    - 중요 변수만 추려 차원 축소

- 주요 도구
    - Pandas : 데이터 조작 전반
    - scikit-learn : 전처리 파이프라인
    - numpy : 수치 연산
    - fit(), transform() 

----------------------------------------------------

D. 모델 학습
- 모델은 데이터 속 패턴을 수식으로 압축한다. 학습이란 그 수식의 파라미터를 최적화하는 과정이다.

1. 지도 학습(Supervised)
    - 분류 : 로지스틱 회귀, 랜덤 포레스트, XGBoost, 신경망
    - 회귀 : 선형 회귀, SVR, 딥러닝

2. 비지도 학습(Unsupervised)
    - 클러스터링 : K-Means, DBSCAN
    - 차원 축소 : PCA, t-SNE

3. 딥러닝(Deep Learning)
    - CNN : 이미지 분류
    - RNN/LSTM : 시계열, 텍스트
    - Transformer : 자연어 처리

과적합 vs. 과소 적합
    - 과적합(Overfitting) : 훈련 데이터에만 잘 맞고 새 데이터에 실패 → 드롭아웃, 정규화로 해결
    - 과소적합(Underfitting) : 모델이 너무 단순해 패턴을 못잡음 → 모델 복잡도 증가

----------------------------------------------------

E. 평가 및 배포
- 좋은 모델은 실험실에서 끝나지 않는다. 실제 환경에서 작동해야 비로소 가치를 만든다.

- 평가 지표(Metrics)
    - 정확도(Accuracy) : 전체 중 맞춘 비율, 클래스 불균형 시 주의
    - 정밀도 / 재현율 (Precision / Recall) : 스팸 탐지, 의료 진단 등 비대칭 문제에 핵심
    - F1-Score : 정밀도와 재현율의 조화 평균
    - AUC-ROC : 이진 분류 모델의 전반적 성능 측정

- 배포 후 모니터링 중요성
    - 데이터 드리프트(Data Drift) : 실제 데이터 분포가 학습 데이터와 달라지는 현상
    - 모델 성능 저하 감지 → 재학습(Retraining) 주기 설정
    - A/B 테스트로 신규 모델 점진적 허용

----------------------------------------------------

```

- 데이터 기반 문제 정의
    - 잘못된 문제 정의 : "AI로 매출을 올리고 싶다."
        - 측정 불가, 목표 불명확, 데이터 연결 X
    - 올바른 문제 정의 : "고객 이탈률을 30일 이내에 15% 이상 줄이기 위해, 최근 6개월 구매 이력 데이터를 기반으로 이탈 가능 고객을 예측한다."
        - 측정 지표 명확(이탈률 15%), 데이터 소스 특정(구매이력), 기간 한정(30일, 6개월)

<br/>

- 가치 창출 프로세스 : 데이터 → 인사이트 → 행동
    - Raw Data : 수집된 원시 데이터
    - Information : 정제된 데이터와 패턴
    - Knowledge : 모델, 통계 기반 인사이트
    - Action : 의사결정 및 개선 실행

- 데이터 자체는 가치가 없고, 가공과 해석 과정이 가치를 만들며 AI는 이를 자동화, 가속화 함

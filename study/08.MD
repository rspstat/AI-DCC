### 8. 오디오 딥러닝과 응용 모델

오디오 딥러닝 종류

- Audio Classification
    - 입력 : 오디오 구간
    - 출력 예시 : 개, 자동차, 비, 천둥

- Sound event detection 
    - 입력 : 긴 오디오
    - 출력 예시 : 이벤트 종류와 발생 시간

- Speech recognition
    - 입력 : 음성
    - 출력 예시 : 발화 내용 또는 문장

- Audio regression
    - 입력 : 오디오
    - 출력 예시 : 소음 크기, 감정 강도, 품질 점수

Single-label classification
- 한 오디오에 하나의 정답
- yes, no, stop, go 중 하나

Multi-label classification
- 한 오디오에 여러 정답
- rain + thunder + wind

---

- 같은 CNN을 사용하더라도 한 오디오에 하나의 정답만 존재하는지, 여러 소리가 동시에 존재할 수 있는지에 따라 출력층과 손실함수가 달라짐
- Audio classification은 전체 파일에 하나 또는 여러 개의 label 예측
- Sound event detection은 어떤 소리가 포함되어 있는지 뿐 아니라 언제 시작하고 끝났는지 예측

Con't

---

Audio 증강

- 동일한 사람이 동일한 단어를 말하더라도 여러 요인에 따라 Waveform과 Spectrogram은 달라짐
- 모델이 조용한 환경에서 음성만 학습하면 단어 자체의 특징 + 꺠끗한 녹음 조건까지 함께 학습 가능
- 이후 실제 환경에서 노이즈가 포함된 음성이 들어오면 같은 단어여도 새로운 종류의 입력으로 받아들임
- 이러한 문제 완화를 위해 학습 데이터에 여러 버전의 녹음 조건을 경험하게 함
- 이를 Audio augmentation

---

Noise Augmentation

- 실제 배경 노이즈를 원래 오디오에 추가하여 다양한 녹음 환경 모사
- 노이즈의 종류와 크기 중요
- 산림 환경에서 오디로를 분석하면 -> 바람, 비, 곤충, 차량, 센서 잡음이 노이즈
- 실내 음성 -> 에어컨, 키보드, 사람들 대화 등
- "최대한 원본 음성을 방해하지 않는 선에서 Noise 증강 적용"

Wav2Vec2

- 정답 문장이 없는 대규모 음성 데이터에서 일부 구간을 가리고, 주변 문맥을 이용해 해당 구간의 올바른 음성 표현을 찾게함
- Wav2Vec2 2.0은 Raw waveform에서 일반적인 음성 표현을 먼저 학습한 뒤, 새로운 음성 문제에 대해 Fine-tuning 한 모델이다.

멀티모달 (Multimodal) 딥러닝

- 1. 모달리티(Modality)
    - 우리가 세상을 인식하는 정보의 종류나 형태를 의미(예: 시각, 청각, 텍스트, 촉각 등)
    - 지금까지 우리는 주로 단일 모달(Single-modal), 즉 한 종류의 데이터만 다루었으나. (예: 이미지, 텍스트 등)

- 2. 멀티모달(Multimodal)
    - 두 가지 이상의 모달리티 데이터를 함께 사용하여, 단일 모달리티를 사용했을 때보다 더 높은 수준의 이해와 추론을 목표로 하는 AI 분야
    - 핵심 : 사람처럼 여러 감각을 함께 사용하는 인간의 학습방식 모방

---

모달리티 융합 종류

- 서로 다른 두 데이터를 합치는(Fusion) 3가지 존재
    - Early Fusion
        - 각 데이터를 전처리 한 후, 모델에 입력하기 전에 입력단에서 합침
    - Late Fusion
        - 각 데이터에 대해 독립적인 모델을 따로따로 통과 후, 최종 결과(예측값)을 합치는 방식
    - Joint or Intermediate Fusion
        - 각 데이터가 별도의 인코더를 통과하여 특징을 추출한 뒤, 모델의 중간 레이어에서 이 특징들을 합치는 방식
        - 가장 많이 사용됨

멀티모달 Task 이해

- 서로 다른 Image 데이터들을 Fusion하여 활용한 예시들

1) 의료 영상 융합 (Medical Image Fusion)

    - 입력 : CT/MRI (해부학적 구조) + PET (기능적/대사 활동)
    - 출력 : 두 정보가 결합된 진단용 융합 이미지
    - 목표 : 암세포의 정확한 위치(CT/MRI)와 활성도(PET)를 동시에 파악하여 진단 및 치료 계획의 정확도를 높입니다

2) 위성/항공 영상 융합 (Satellite/Aerial Image Fusion)

    - 입력 : 저해상도 다중분광(컬러) 이미지 + 고해상도 전정색(흑백) 이미지
    - 출력 : 고해상도 다중분광(컬러) 융합 이미지 (Pansharpening)
    - 목표 : 각기 다른 장점을 가진 위성 센서 정보를 합쳐, 색상과 해상도를 모두 만족하는 고품질 이미지를 생성합니다

3) RGB-D 이미지 융합 (RGB + Depth Image Fusion)

    - 입력 : RGB 컬러 이미지 + Depth (깊이) 이미지
    - 출력 : 객체 분할 마스크, 3D 장면 재구성 등
    - 목표 : 컬러 정보만으로는 알기 어려운 객체의 3차원 형태와 거리를 깊이 정보로 보강하여, 더 정확한 장면 이해, 객체 분할, 자율주행 등에 활용합니다

---

멀티모달의 미래

- 패러다임 전환 : 과거에는 각 데이터(이미지, 텍스트)를 처리하는 모델을 따로 만들어 '융합'하는 방식이 일반적
- 이제는 처음부터 세상의 모든 데이터(이미지, 오디오, 비디오 등)를 한 번에 학습하는 초거대 모델, LLM (Large Multimodal Model)이 대세가 되어있음
- 데이터 융합 + 여러 종류의 데이터를 넘나들며 하나의 대화속에서 종합적으로 추론하고 소통

---

멀티모달의 Challnge 들

| 문제 | 설명 |
|---|---|
| 시간 정렬 | Audio, Video, Sensor의 기록 시간이 다를 수 있음 |
| Sampling 간격 | Audio는 초당 수천 개, 기상자료는 분·시간 단위 |
| Missing modality | 일부 시점에 영상이나 오디오가 없을 수 있음 |
| 품질 차이 | 한 Modality만 매우 강하거나 매우 noisy할 수 있음 |
| Modality dominance | 모델이 한 데이터 유형에만 의존할 수 있음 |
| 데이터 누수 | 같은 장소·세션이 Train과 Validation에 포함될 수 있음 |
| 계산량 | 여러 Encoder를 함께 사용하므로 비용 증가 |

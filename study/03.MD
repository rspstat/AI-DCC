TP/TN/FP/FN

![alt text](/study/img/13.png)

- TP : 실제 P인 정답을 P라고 예측 (True)
- TN : 실제 P인 정답을 N이라고 예측 (True)
- FP : 실제 N인 정답을 P라고 예측 (False) -> Type I error
- FN : 실제 N인 정답을 N이라고 예측 (False) -> Type II error

이때, 긍정과 부정에 관계없이 우리가 관심있는 결과가 Positive 가 됨을 명심.

재현율(Recall)

![alt text](/study/img/17.png)

- 실제 정답 True 중 분류기가 True로 예측한 비율
- TP / TP + FN

---

정밀도(Precision)

![alt text](/study/img/18.png)

- True로 예측한 것들 중 실제 True 인 비율
- 언제나 True로 답하는 분류기는 Recall이 1이지만 Precision은 0에 가까움
- 단점 : Recall의 장점이 Precision의 단점, 서로 반대 개념
- TP / TP + FP

---

Threshold
- 재현율(Recall) : 실제로 정답이 True인 것들 중 True로 예측한 비율
- 정밀도(Precision) : True로 예측한 것들중 실제 답이 True인 비율

![alt text](/study/img/19.png)

- Threshold : 모델을 0, 1로 나누는 기준
- E.g) 모델의 Threshold가 0.5이면 0.5보다 작으면 0, 크면 1로 예측

---

F1-Score

![alt text](/study/img/20.png)

- 2 * 정밀도 * 재현율 / 정밀도 + 재현율
- F1-Score : 재현율과 정밀도의 조화 평균
    - 반대 개념인 두 지표를 균형있게 반영, 어느 한쪽에 치우치지 않을 수록 커짐

Ex) Recall = 1, Precision = 0.01 분류기
- 산술 평균 : (1+0.01) / 2 = 0.505
- 조화 평균 : 2 * 1 * 0.01 / 1 + 0.01 = 0.019

---

비용이 최소화되는 W, b를 찾아야함

- How? 
    - 해석적 방법 : 직접 미분해서 0이 되는 지점 계산
    - 경사하강법(Gradient Descent) : 기울기 따라 점진적 이동
        - 변수가 많을 땐 경사하강법이 기준

해석적 방법 - 미분 이용
- 정규 방정식 
- 비용 함수가 Convex -> 전역 최솟값 1개 존재
- 변수 x가 많으면 역행렬 계산이 아주 무거움

---

경사하강법의 물음들

1. 왜 경사하강법인가?
    - 실제 함수는 미분계수 구하기 힘듦
    - 계산 복잡도가 너무 큼
    - iteration 방법 활용

2. 우리는 무엇을 찾는가?
    - 입력 x는 고정, 변하는 것은 파라미터 theta
    - 선형회귀에서는 theta = 직선의 기울기
    - MSE(theta)의 최솟점을 찾는 theta
    - 우리가 찾는 것은 theta, beta, gamma

Learning Rate - 보폭의 문제
- 경사하강법은 한 걸음씩 비용이 작아지는 곳으로 이동
- 보폭은? -> 그것이 Learning Rate(alpha)
- 매 step마다 기울기 * alpha 만큼 파라미터 업데이트
- alpha 설정은 설계자의 몫 (대표적 하이퍼파라미터)

1. 원시 텍스트 : 문자열

생성형 AI의 이해 : GAN
- AI는 원본 데이터의 분포를 학습해 새로운 데이터 생성
- GAN은 진짜/가짜를 구별하는 판별자와 진짜같은 이미지를 만드는 생성자가 경쟁하며 학습
- 이미지는 픽셀값으로 이루어진 숫자 행렬이며, GAN은 그 행렬의 패턴과 분포를 모방해 실제 같은 결과를 만듦.

GAN 학습 과정 : 노이즈 -> 이미지
- Epoch 1 : 완전한 랜덤 노이즈 (픽셀 무작위 분포)
- Epoch 10 : 희미한 윤곽 등장, 형태 보임
- Epoch 50 : 눈, 코, 입 형성, 특징 구분
- Epoch 200+ : 고품질 이미지 생성

분포란 무엇인가?
- 데이터가 어떤 값에 얼마나 자주 나타나는지를 나타내는 함수
- 확률 밀도 함수(PDF) : 연속형 데이터의 분포
- 확률 질량 함수(PMF) : 이산형 데이터의 분포
- 누적 분포 함수(CDF) : P(X <= x) 를 나타냄

분포를 알아야하는 이유

1. 이상치 탐지 : 분포 꼬리 부분의 값 식별
2. 모델 선택 : 분포 가정에 맞는 알고리즘 선택
3. 전처리 방향 : 정규화, 로그 변환 필요 여부 판단
4. 가설 검정 : 통계적 유의성 판단의 기반

정규 분포 
- 자연 현상(키, 몸무게, 측정 오차)에서 가장 흔히 나타내는 종 모양 분포
- 평균과 표준편차로 정의
- 평균 = 중앙값 = 최빈값
- +-1a 에 68%, +-2a에 95%,+-3a 에 99.7%
- 표준 정규 분포 : 평균 = 0, 표준편차 = 1로 표준화한 형태

AI에서의 활용
- 가중치 초기화 (Xavier, He 초기화)
- 잔차(Resuidual) 분포 확인
- 가우시안 노이즈 추가(데이터 증강)

---

균등 분포 
- 모든 구간에서 동일한 확률을 가지는 분포, 연속형/이산형 모두 존재

- 연속 균등 분포
- $f(x) = 1 / b-a' (a <= x <= b)$
- 평균 : $(a + b) / 2$
- 분산 : ${(b - a)^2/12}$

분포 형태 분석 - 왜도&첨도

---

왜도(Skewness) - 비대칭성
- 분포가 평균을 기준으로 얼마나 비대칭인가?

![alt text](/study/img/8.png)

- 왜도 = 0 : 완전 대칭
- 왜도 > 0 : 양의 왜도 -> 오른쪽 꼬리가 긺, 소득, 자산 등의 데이터에 흔함, 로그 변환 권장
- 왜도 < 0 : 음의 왜도 -> 왼쪽 꼬리가 긺, 시험 점수 등에 흔함.

---

첨도(Kurtosis) - 뾰족함
- 분포의 꼬리가 얼마나 두껍고 중심이 얼마나 뾰족한지를 나타내는 지표

![alt text](/study/img/9.png)

- 첨도 = 3 (정규분포 기준) : Mesokutic : 정규분포와 동일한 꼬리 두께
- 첨도 > 3 (Leptokurtic) : 뾰족하고 꼬리가 두꺼움, 이상치.
- 첨도 < 3 (Platykurtic) : 납작하고 꼬리가 얇음, 균등분포에 가까움

---

실전 팁 : |왜도| > 1 이면 로그 변환, |왜도| > 2이면 Box-Cox 변환을 고려. 첨도가 높으면 이상치 처리 후 재확인.

---

EDA에서 왜도, 첨도가 중요한 이유

1. 전처리 방향 결정
- |왜도| < 0.5 : 변환 필요
- 0.5 <= |왜도| < 1 : 로그 변환
- |왜도| >= 1 or 첨도 높음 : 강한 변환 필요


EDA 실전 순서

1. df.describe()로 기초 통계 확인
2. df.skew() / df.kurtosis()로 왜도, 첨도 수치 확인
3. 히스토그램 + KDE로 분포 시각화
4. 왜도 기준으로 변환 전략 결정 후 재확인

---

왜도와 첨도는 단순한 통계 수치가 아님, EDA의 모든 후속 결정을 좌우하는 시스템.

모델 선택 기준
- 선형 회귀 / 로지스틱 회귀 : 피처가 정규분포에 가까울수록 안정적
- 트리 기반 모델 : 왜도, 첨도에 강건, 변환 없이도 작동 가능
- 신경망 : 왜도가 크면 학습 불안정 위험
- 나이브 베이즈 : 정규 분포 가정 -> 왜도 높으면 성능 급락

이상치 탐지 신호
- 첨도 > 5 : 꼬리가 두꺼움. -> IQR/Z-Score 탐지 수행
- 왜도 < 2 : 한쪽 방향으로 극단값이 분포를 왜곡 중 -> 박스 플롯으로 시각 확인

```py
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

# 왜도, 첨도 일괄 확인
skew_df = pd.DataFrame({
'skewness' : df.skew(), 
'kurtosis' : df.kurtosis()
}).sort_values('skewness', ascending=False)
print(skew_df)

# 왜도 높은 피처 시각화
high_skew = skew_df[skew_df['skewness'].abs() > 1].index
df[high_skew].hist(bins=30, figsize(12, 6))
plt.tight_layout()
plt.show()
```

```py
plt.plot(epochs, val_loss, label='Val Loss')
plt.legend()
```

4. 모델 기반 처리 : is_null_flag를 새 피처로 생성, 결측 패턴이 의미 있으면 효과적

이상치를 처리해야하는 이유
1. 평균, 분산 왜곡
2. 선형 모델 성능 급락
3. 정규화 스케일 오염

처리 전 반드시 물어야 할 질문
1. 이 이상치는 입력 오류? 실제 현상?
2. 분석 목표가 이상치 탐지 자체인가?
3. 이상치 제거 후 데이터 분포가 어떻게 바뀌는가?

이상치가 오히려 핵심인 경우
1. 금융 사기 탐지 : 사기는 극 소수 이상치
2. 의료 이상 탐지 : 극단값이 환자
3. 제조 불량 탐지 : 센서 데이터 벗어남

상황 별 처리 전략
1. 입력 오류 -> 제거 or 결측치로 대체
2. 극단값이지만 실제 데이터 -> IQR 클리핑(상, 하한 고정)
3. 이상치가 분석 목표 -> 제거 금지, 별도 라벨링

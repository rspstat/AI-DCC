### 5차시 미니퀴즈 — CNN 필터·풀링(Pooling)

* **Q1. 입력 데이터는 채널 수와 상관없이 필터 별로 1개의 피처 맵이 만들어진다.**

* **정답:** O
    * **이유:** 필터(커널)는 입력 데이터와 동일한 채널 수를 가지도록 구성되어 각 채널별 연산 결과가 모두 합산되므로, 입력 채널 수와 무관하게 필터 1개당 1개의 피처 맵이 생성됨

<br/>

* **Q2. Pooling 레이어는 학습대상 파라미터가 없다.**

* **정답:** O
    * **이유:** Pooling은 Max나 Average 같은 고정된 연산 규칙으로 값을 추출할 뿐 별도로 학습되는 가중치나 편향이 존재하지 않음

<br/>

* **Q3. Pooling 레이어를 통과하면 행렬의 크기 감소한다.**

* **정답:** O
    * **이유:** Pooling은 일정 크기의 윈도우 내에서 값을 하나로 축약하는 연산이므로 통과 후 특징 맵의 가로·세로 크기(행렬 크기)가 감소함

<br/>

* **Q4. Pooling 레이어를 통과하면 채널 수가 변경되지 않는다.**

* **정답:** O
    * **이유:** Pooling은 각 채널에 대해 독립적으로 연산을 수행하며 채널을 합치거나 늘리지 않으므로 통과 전후로 채널 수는 그대로 유지됨

### 6차시 미니퀴즈 — 텍스트 데이터와 NLP 기초

* **Q1. 다음 중 TF-IDF를 이용한 텍스트 분류 모델의 올바른 학습 절차로 가장 적절한 것은?**
    * ① 전체 텍스트 데이터로 TF-IDF Vectorizer를 먼저 학습한 후, 데이터를 Train과 Validation으로 나눈다
    * ② 데이터를 Train과 Validation으로 먼저 나눈 후, Train 데이터로 TF-IDF Vectorizer를 학습하고 Validation 데이터에는 Transform만 적용한다
    * ③ Token ID가 클수록 해당 단어가 문장 분류에 더 중요한 단어이므로, Token ID 값을 모델의 입력 점수로 사용한다
    * ④ Bigram을 사용하면 문장의 전체 문맥을 이해할 수 있으므로 별도의 Validation 데이터 없이 모델 성능을 평가할 수 있다

* **정답:** ② 데이터를 Train과 Validation으로 먼저 나눈 후, Train 데이터로 TF-IDF Vectorizer를 학습하고 Validation 데이터에는 Transform만 적용한다
    * **이유:** TF-IDF Vectorizer를 전체 데이터로 먼저 학습하면 Validation 데이터의 정보가 Train 과정에 유출되는 데이터 누수(Data Leakage)가 발생하므로, 반드시 Train 데이터로만 fit한 뒤 Validation 데이터에는 transform만 적용해야 함

### 7차시 미니 퀴즈 - 오디오 데이터 이해와 특징 추출

* **Q1. 16 kHz로 저장된 2초 오디오는 몇 개의 Sample을 가지는가?**

* **정답:** 32,000개
    * **이유:** 샘플링 레이트(Sampling Rate) 16 kHz는 1초당 16,000개의 샘플을 의미하므로, 2초 길이의 오디오는 $16{,}000 \times 2 = 32{,}000$개의 샘플을 가짐

<br/>

* **Q2. Spectrogram에서 가로축과 세로축은 각각 무엇인가?**

* **정답:** 가로축은 시간(Time), 세로축은 주파수(Frequency)
    * **이유:** Spectrogram은 시간에 따른 주파수 성분의 변화를 시각화한 것으로, 가로축은 시간의 흐름을 나타내고 세로축은 주파수를 나타내며 색상(진하기)으로 해당 주파수의 에너지(진폭) 크기를 표현함

중단되면 같은 명령어로 다시 실행하면 마지막 epoch 다음부터 이어서 학습합니다.
--data_root는 Training/, Validation/ 폴더가 들어있는 대학부 데이터 폴더입니다.

주요 인자
| 인자 | 기본값 | 설명 |
|---|---|---|
| --loss | posw | posw(pos_weight = Train 음성/양성) 또는 none |
| --seed | 42 | 팀 공통 seed: 42, 123, 2026 |
| --model_name | klue/roberta-base | large는 klue/roberta-large (backbone lr 자동 1e-5) |
| --batch_size | 16 | GPU 메모리 부족 시 8 |
| --max_len | 512 | |
| --epochs / --patience | 8 / 3 | macro-F1 기준 early stopping |
| --backbone_lr / --head_lr | 2e-5 / 1e-3 | |
| --tag | (없음) | 새 설정을 시험할 때 run 이름에 메모 추가 (기존 결과 덮어쓰기 방지) |

출력 (out_dir/{run_name}/)
log.csv: epoch별 loss, macro-F1, lr, 클래스별 F1
val_probs.csv: best epoch 확률 (call_id, prob_{라벨} ×9, true_{라벨} ×9) → 앙상블용
best.pt, latest.pt: 체크포인트 (base 약 440MB씩)
args.json: 실행 설정 기록

규칙 (꼭 지켜주세요)
loss는 posw 또는 none만 사용 (멘토 답변: Train 비율 근거만 허용, Validation 보고 고르기 불허)
새 설정은 Train 근거로 미리 정하고 한 번 실행, 결과가 나빠도 그대로 기록
threshold는 0.5 고정, Validation은 평가·best epoch 선택에만 사용
비교 기준: posw 단일 0.6144 ± 0.0031 / posw 3-seed 앙상블 0.6246 / 팀 최종(KLUE posw + Kc none) 0.6543

message.txt:
"""
Mission 3 (환자 증상 인식) - KLUE-RoBERTa 멀티라벨 분류 학습 스크립트

공통 설정 (팀 통일안)
- 공식 Training으로 학습, 공식 Validation은 평가·best epoch 선택에만 사용 (역전파 X)
- 입력: utterances를 startAt 순 정렬 → text만 공백 연결 (화자 태그 없음)
- 라벨: 공식 9개 (순서 고정), 판정 threshold 0.5 고정 (prob >= 0.5 → 1)
- best epoch 기준: macro-F1
- loss: posw (pos_weight = Train 음성수/양성수) 또는 none (가중치 없음)
  ※ 멘토 답변: pos_weight는 Train 비율 근거면 허용, Validation 보고 고르는 건 불허

사용 예시
  python train_klue.py --data_root "/path/대학부 데이터" --out_dir ./runs --loss posw --seed 42
  python train_klue.py --cache_dir ./cache --out_dir ./runs --loss none --seed 123
  python train_klue.py ... --model_name klue/roberta-large      # large는 backbone lr 자동 1e-5

출력 (out_dir/{run_name}/)
  log.csv        epoch별 loss, macro-F1, lr, 클래스별 F1
  val_probs.csv  best epoch 기준 확률 (call_id, prob_{라벨} x9, true_{라벨} x9) - 앙상블용
  best.pt        best macro-F1 체크포인트
  latest.pt      매 epoch 저장 (중단 시 같은 명령어로 재실행하면 이어서 학습)
"""
import argparse
import glob
import json
import os
import random
import time

import numpy as np
import pandas as pd
import torch
import torch.nn as nn
from sklearn.metrics import f1_score
from torch.utils.data import DataLoader, Dataset
from tqdm.auto import tqdm
from transformers import AutoModel, AutoTokenizer, get_linear_schedule_with_warmup

TARGET_SYMPTOMS = ["고열", "구토", "두통", "복통", "어지러움",
                   "열상", "오심", "전신쇠약", "호흡곤란"]
THRESHOLD = 0.5


# ---------------------------------------------------------------- 데이터
def build_input_text(data):
    utts = sorted(data['utterances'], key=lambda u: u['startAt'])
    return " ".join(u['text'] for u in utts)          # 화자 태그 없음 (규정)


def to_multihot(symptoms):
    return [1 if s in symptoms else 0 for s in TARGET_SYMPTOMS]


def parse_files(files):
    rows = []
    for fp in tqdm(files, desc='parse'):
        with open(fp, encoding='utf-8') as f:
            data = json.load(f)
        rows.append({'call_id': os.path.splitext(os.path.basename(fp))[0],
                     'text': build_input_text(data),
                     'labels': to_multihot(data.get('symptom', []))})
    return pd.DataFrame(rows)


def load_data(args):
    """캐시(pkl)가 있으면 로드, 없으면 data_root의 라벨 JSON을 파싱해서 캐시 저장"""
    tr_cache = os.path.join(args.cache_dir, 'parsed_train.pkl')
    va_cache = os.path.join(args.cache_dir, 'parsed_val.pkl')
    if os.path.exists(tr_cache) and os.path.exists(va_cache):
        print("캐시 로드:", args.cache_dir)
        return pd.read_pickle(tr_cache), pd.read_pickle(va_cache)

    if not args.data_root:
        raise ValueError("캐시가 없으면 --data_root (대학부 데이터 폴더)가 필요합니다.")
    all_json = glob.glob(os.path.join(args.data_root, '**', '*.json'), recursive=True)
    tr_files = sorted(p for p in all_json if f'{os.sep}Training{os.sep}2.라벨링데이터{os.sep}' in p)
    va_files = sorted(p for p in all_json if f'{os.sep}Validation{os.sep}2.라벨링데이터{os.sep}' in p)
    print(f"JSON: Training {len(tr_files)} / Validation {len(va_files)}")
    train_df, val_df = parse_files(tr_files), parse_files(va_files)
    os.makedirs(args.cache_dir, exist_ok=True)
    train_df.to_pickle(tr_cache)
    val_df.to_pickle(va_cache)
    return train_df, val_df


class SymptomDataset(Dataset):
    def __init__(self, df, tokenizer, max_len):
        self.call_ids = df['call_id'].tolist()
        enc = tokenizer(df['text'].tolist(), truncation=True, max_length=max_len,
                        return_token_type_ids=False)       # RoBERTa는 token_type_ids 미사용
        self.input_ids, self.attn = enc['input_ids'], enc['attention_mask']
        self.labels = df['labels'].tolist()

    def __len__(self):
        return len(self.call_ids)

    def __getitem__(self, i):
        return {'input_ids': self.input_ids[i], 'attention_mask': self.attn[i],
                'labels': self.labels[i], 'call_id': self.call_ids[i]}


class Collator:
    """dynamic padding: 배치 안에서 가장 긴 길이에 맞춰 padding"""
    def __init__(self, tokenizer):
        self.tokenizer = tokenizer

    def __call__(self, batch):
        padded = self.tokenizer.pad(
            [{'input_ids': b['input_ids'], 'attention_mask': b['attention_mask']} for b in batch],
            padding='longest', return_tensors='pt')
        padded['labels'] = torch.tensor([b['labels'] for b in batch], dtype=torch.float)
        padded['call_id'] = [b['call_id'] for b in batch]
        return padded


# ---------------------------------------------------------------- 모델
class SymptomClassifier(nn.Module):
    def __init__(self, model_name, num_classes=9, dropout=0.3):
        super().__init__()
        self.backbone = AutoModel.from_pretrained(model_name, add_pooling_layer=False)
        h = self.backbone.config.hidden_size
        self.classifier = nn.Sequential(
            nn.Linear(h, 256), nn.ReLU(), nn.Dropout(dropout), nn.Linear(256, num_classes))

    def forward(self, input_ids, attention_mask):
        x = self.backbone(input_ids=input_ids, attention_mask=attention_mask).last_hidden_state
        m = attention_mask.unsqueeze(-1).to(x.dtype)
        pooled = (x * m).sum(1) / m.sum(1).clamp(min=1e-9)     # mean pooling
        return self.classifier(pooled)


# ---------------------------------------------------------------- 학습/평가
def set_seed(seed):
    random.seed(seed)
    np.random.seed(seed)
    torch.manual_seed(seed)
    torch.cuda.manual_seed_all(seed)


@torch.no_grad()
def evaluate(model, loader, device, use_amp):
    model.eval()
    probs, labels, ids = [], [], []
    for batch in loader:
        with torch.autocast(device_type=device.type, enabled=use_amp):
            logits = model(batch['input_ids'].to(device), batch['attention_mask'].to(device))
        probs.append(torch.sigmoid(logits.float()).cpu())
        labels.append(batch['labels'])
        ids += batch['call_id']
    probs, labels = torch.cat(probs).numpy(), torch.cat(labels).numpy()
    preds = (probs >= THRESHOLD).astype(int)                     # 공식 규정: >= 0.5
    macro = f1_score(labels, preds, average='macro', zero_division=0)
    per_cls = f1_score(labels, preds, average=None, zero_division=0)
    return macro, per_cls, probs, labels, ids


def save_probs_csv(path, ids, probs, labels):
    df = pd.DataFrame({'call_id': ids})
    for i, s in enumerate(TARGET_SYMPTOMS):
        df[f'prob_{s}'] = probs[:, i]
    for i, s in enumerate(TARGET_SYMPTOMS):
        df[f'true_{s}'] = labels[:, i].astype(int)
    df.to_csv(path, index=False, encoding='utf-8-sig')


def main():
    ap = argparse.ArgumentParser()
    ap.add_argument('--data_root', default=None, help="'대학부 데이터' 폴더 (Training/Validation 포함)")
    ap.add_argument('--cache_dir', default='./cache', help='parsed_train.pkl / parsed_val.pkl 위치')
    ap.add_argument('--out_dir', default='./runs')
    ap.add_argument('--model_name', default='klue/roberta-base')
    ap.add_argument('--loss', choices=['posw', 'none'], default='posw')
    ap.add_argument('--seed', type=int, default=42)
    ap.add_argument('--epochs', type=int, default=8)
    ap.add_argument('--patience', type=int, default=3)
    ap.add_argument('--batch_size', type=int, default=16)
    ap.add_argument('--max_len', type=int, default=512)
    ap.add_argument('--backbone_lr', type=float, default=None, help='기본: base 2e-5 / large 1e-5')
    ap.add_argument('--head_lr', type=float, default=1e-3)
    ap.add_argument('--warmup_ratio', type=float, default=0.1)
    ap.add_argument('--tag', default='', help='run 이름 뒤에 붙일 메모 (예: drop0.1)')
    args = ap.parse_args()

    if args.backbone_lr is None:
        args.backbone_lr = 1e-5 if 'large' in args.model_name else 2e-5

    device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
    use_amp = device.type == 'cuda'
    if device.type == 'cpu':
        print("경고: GPU가 없습니다. CPU 학습은 매우 느립니다.")

    model_tag = args.model_name.split('/')[-1]
    run_name = f'{model_tag}_meanpool_{args.loss}_len{args.max_len}_seed{args.seed}'
    if args.tag:
        run_name += f'_{args.tag}'
    run_dir = os.path.join(args.out_dir, run_name)
    os.makedirs(run_dir, exist_ok=True)
    latest_ckpt = os.path.join(run_dir, 'latest.pt')
    best_ckpt = os.path.join(run_dir, 'best.pt')
    log_path = os.path.join(run_dir, 'log.csv')
    with open(os.path.join(run_dir, 'args.json'), 'w', encoding='utf-8') as f:
        json.dump(vars(args), f, ensure_ascii=False, indent=2)
    print("RUN:", run_name)

    # 데이터
    train_df, val_df = load_data(args)
    print(f"Train {len(train_df)} / Val {len(val_df)}")
    tokenizer = AutoTokenizer.from_pretrained(args.model_name)
    collate = Collator(tokenizer)
    train_ds = SymptomDataset(train_df, tokenizer, args.max_len)
    val_ds = SymptomDataset(val_df, tokenizer, args.max_len)
    val_loader = DataLoader(val_ds, batch_size=32, shuffle=False, collate_fn=collate)

    set_seed(args.seed)
    g = torch.Generator().manual_seed(args.seed)
    train_loader = DataLoader(train_ds, batch_size=args.batch_size, shuffle=True,
                              collate_fn=collate, generator=g)

    # loss (pos_weight는 Train 비율로만 계산)
    y = np.array(train_df['labels'].tolist())
    if args.loss == 'posw':
        w = (len(y) - y.sum(0)) / y.sum(0)
        pw = torch.tensor(w, dtype=torch.float, device=device)
        print("pos_weight:", dict(zip(TARGET_SYMPTOMS, np.round(w, 2))))
    else:
        pw = None
    criterion = nn.BCEWithLogitsLoss(pos_weight=pw)

    # 모델/옵티마이저
    model = SymptomClassifier(args.model_name).to(device)
    print(f"{args.model_name}: {sum(p.numel() for p in model.parameters()) / 1e6:.1f}M params")
    optimizer = torch.optim.AdamW([
        {'params': model.backbone.parameters(), 'lr': args.backbone_lr},
        {'params': model.classifier.parameters(), 'lr': args.head_lr}], weight_decay=0.01)
    total_steps = len(train_loader) * args.epochs                 # 항상 전체 epoch 기준
    scheduler = get_linear_schedule_with_warmup(optimizer, int(args.warmup_ratio * total_steps), total_steps)
    scaler = torch.amp.GradScaler(device.type, enabled=use_amp)

    # 재개
    start_epoch, best_f1, bad_epochs = 0, 0.0, 0
    if os.path.exists(latest_ckpt):
        ck = torch.load(latest_ckpt, map_location=device)
        model.load_state_dict(ck['model'])
        optimizer.load_state_dict(ck['optimizer'])
        scheduler.load_state_dict(ck['scheduler'])
        scaler.load_state_dict(ck['scaler'])
        start_epoch, best_f1, bad_epochs = ck['epoch'] + 1, ck['best_f1'], ck['bad_epochs']
        print(f"재개: epoch {start_epoch + 1}부터, best {best_f1:.4f}")
        if bad_epochs >= args.patience:
            print("이미 early stopping으로 종료된 run입니다.")
            return

    def save_ckpt(path, epoch):
        torch.save({'epoch': epoch, 'best_f1': best_f1, 'bad_epochs': bad_epochs,
                    'model': model.state_dict(), 'optimizer': optimizer.state_dict(),
                    'scheduler': scheduler.state_dict(), 'scaler': scaler.state_dict(),
                    'args': vars(args)}, path)

    for epoch in range(start_epoch, args.epochs):
        t0 = time.time()
        model.train()
        total = 0.0
        for batch in tqdm(train_loader, desc=f'epoch {epoch + 1}', leave=False):
            optimizer.zero_grad()
            with torch.autocast(device_type=device.type, enabled=use_amp):
                logits = model(batch['input_ids'].to(device), batch['attention_mask'].to(device))
            loss = criterion(logits.float(), batch['labels'].to(device))
            scaler.scale(loss).backward()
            scaler.step(optimizer)
            scaler.update()
            scheduler.step()
            total += loss.item()
        train_loss = total / len(train_loader)

        macro, per_cls, probs, labels, ids = evaluate(model, val_loader, device, use_amp)
        lr = scheduler.get_last_lr()[0]
        print(f"Epoch {epoch + 1}/{args.epochs} | loss {train_loss:.4f} | macro-F1 {macro:.4f} | "
              f"lr {lr:.2e} | {time.time() - t0:.0f}s", flush=True)
        row = {'epoch': epoch + 1, 'loss': train_loss, 'macro_f1': macro, 'lr': lr,
               **{f'f1_{s}': f for s, f in zip(TARGET_SYMPTOMS, per_cls)}}
        pd.DataFrame([row]).to_csv(log_path, mode='a', index=False,
                                   header=not os.path.exists(log_path))

        if macro > best_f1:
            best_f1, bad_epochs = macro, 0
            save_ckpt(best_ckpt, epoch)
            save_probs_csv(os.path.join(run_dir, 'val_probs.csv'), ids, probs, labels)
            print(f"  -> best 갱신 {best_f1:.4f}", flush=True)
        else:
            bad_epochs += 1
        save_ckpt(latest_ckpt, epoch)
        if bad_epochs >= args.patience:
            print("Early stopping")
            break

    print(f"완료 | {run_name} | best macro-F1 {best_f1:.4f}")


if __name__ == '__main__':
    main()

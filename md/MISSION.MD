## Mission

AI 크리에이터 캠프
대학부
문제 : 전화대화 음성 및 전사 데이터를 이용한 응급상황 인식
-> AI-hub 119

음성 파일 및 전사 및 annotation 파일 존재 (json)
각 발화 조각들의 정보들

조건
외부 데이터 사용 불가
미션에서 제시하는 입출력만 사용

구글, 지피티 등 api를 사용해서 답을 내면 안됨 (우리가 코드를 짜야함)

서울권 데이터만 사용
validation 폴더는 사용 금지
샘플 전처리 금지
validation 정보만 특별한 처리도 금지

음성 처리 가이드 제시
(ppt 참고) -> 문제에 따라 유리한 방식이 다를 것

미션 1. 신고자 성별 분류
대화를 입력 받아서 (음성) -> 남, 여 분류

미션 2. 신고자/119 대원 분류하기
한 사람의 한 발화 조각을 통해 신고자와 119 대원 분류
(조각의 분류는 대화가 끊기는 것을 기준으로)
음성으로 하기 (annotation, text 사용 불가)
발화에 홀짝으로 분류 금지

미션 3. 환자의 증상 인식
신고자 및 119 대원 대화 텍스트를 사용해서 환자의 증상
(증상 개수는 9개만 취급하며, 여러 개 일수도 있음)

성능 평가도 진행

학습 모델과 추론 코드를 함께 제출
inference를 돌릴 수 있는 코드를 제출해야 함 (코드를 돌려서 평가할 것)

불필요한 코드 넣지 말고, 주석은 필수로 달아주기

내용 :
KLUE-RoBERTa 실험 과정 (Mission 3)

Loss 설정: pos_weight = Train 음성/양성 (posw)
Train 증상별 양성 비율 10~23%로 클래스 불균형 확인
양성 오답 벌점을 음성/양성 비율만큼 확대해 클래스별 기여 균형화
첫 모델(KoBERT)부터 기본값으로 사용, Validation 결과로 변경하지 않음

백본 교체: KoBERT → KLUE-RoBERTa base
KoBERT(2019)가 오래된 모델이라 최신 한국어 사전학습 모델로 교체
loss·head 구조는 유지하고 백본 효과만 비교
macro-F1 0.5880 → 0.6177 (+0.030), KLUE-RoBERTa 채택

입력 길이 확인
토큰 길이 중앙값 230, 512 초과 2.7%
청크 처리·KoBigBird 불필요, max_length 512 뒤쪽 자르기로 결정

예측 성향 분석
posw 결과 9개 클래스 전부 recall > precision (macro P 0.55 / R 0.72)
양성 쪽 과잉 예측 확인, threshold 0.5 고정 규정상 판정선 조정 불가

pos_weight 비교 실험 (ablation)
none: precision 쏠림으로 반전, 오심 recall 0.13까지 하락 (0.6118)
√(음성/양성): P/R 균형 (0.643 / 0.647), 최고 성능 (0.6405)
√ 방식은 Validation 비교로 선택한 것이라 제출 제외

Attention pooling 시도
증상 언급 구간 집중 기대로 mean pooling 대체 시도
0.6378 (mean 0.6405), 차이 없음으로 mean pooling 유지

다중 seed 검증 (42 / 123 / 2026)
단일 결과의 우연 여부 확인 목적 (멘토 권장)
posw 0.6144 ± 0.0031, none 0.6108 ± 0.0023, 결과 안정성 확인
seed 3개 확률 평균 시 posw 0.6246 (+0.010)

roberta-large 시도
모델 용량 확대로 단일 성능 향상 기대
posw에서 base 대비 개선 없음, GPU 비용 대비 효과 부족으로 제외

입력 길이 256 실험
Train 분석 결과 라벨 증상 첫 언급의 97.3%가 256토큰 이내
뒤쪽 동반 증상 언급 제거로 FP 감소 기대, Validation 확인 전 길이 결정
0.6137 (512: 0.6177), precision 개선 없음으로 512 유지, 학습 시간만 40% 단축

오류 분석
FN의 85~98%가 대화에 해당 증상 표현 없음, 텍스트만으로 판단 불가한 데이터 한계
FP 상당수가 대화에서 실제 호소했으나 라벨에 없는 동반 증상
단일 라벨 67%, 라벨의 65.6%가 첫 언급 증상으로 주호소 중심 라벨링 확인
오심은 어지러움(49%)·구토(39%)에 딸려 붙는 부가 증상 성격으로 최하위 F1

팀 앙상블: KLUE-RoBERTa posw + KcELECTRA none
posw(recall형)와 none(precision형)의 상반된 성향으로 상호 보완 기대
서로 다른 백본으로 오류 중복 감소 (예측 불일치율 11.3%)
백본별 seed 3개 평균 후 1:1 평균, 가중치 탐색 없음
0.6543, 단일 백본 앙상블 대비 +0.03, 최종 제출본 후보
